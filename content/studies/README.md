# Studies → Posts

The content engine for the AI-agent-security series.

**Rule:** every study ships a post. The study is scaffolding, not the deliverable.

- `studies/NN-topic.md` — the deep study. Everything I learn: sources, diagrams, dead-ends, full detail.
- `../NN-topic-post.md` — the distilled post. The sharp 20%, public-facing, lighter than the study.

**Arc**
1. Anatomy of an agent — components as a trust-boundary map   ← current
2. The agent loop — reason→act, context, memory: where authority accumulates
3. Trust boundaries & the lethal trifecta — the bridge
4. RAG → MCP → A2A attack surface — DONE (the capstone)
5. onward — attack deep-dives, each with a lab

**Canonical anchor:** the OWASP Agentic Security Initiative — https://genai.owasp.org/initiatives/agentic-security-initiative/
Its *Top 10 for Agentic Applications 2026* (ASI01–ASI10) is the threat taxonomy every study maps back to.

**Lens for the whole series:** Build. Understand. Break. Every component gets tagged
with where trust is established and how it fails — the attacker's anatomy, not the generic explainer.
